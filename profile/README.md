# FlashFoxyCards 🦊

Приложение для изучения английских слов. Работает в браузере — вход через Яндекс ID или VK ID; в Telegram открывается как мини-приложение (Mini App). Устанавливать ничего не нужно.

## Как это работает

1. Открываете приложение: кнопкой меню в [@FlashFoxyCardsBot](https://t.me/FlashFoxyCardsBot) или по адресу [flashfoxycards.ru](https://flashfoxycards.ru) в браузере
2. Вход подтверждаете через Яндекс ID или VK ID — короткое подтверждение на стороне провайдера, и словарь везде один и тот же
3. Вводите английские слова по одному или списком, можно с уточнением значения
4. Нейросеть собирает по каждому слову готовую карточку: транскрипция, перевод всех значений, частотные словосочетания с примерами, уровень сложности
5. Приложение само решает, когда показать карточку снова, — по алгоритму интервальных повторений FSRS слово возвращается именно тогда, когда начинает забываться

На телефоне откройте сайт в браузере и выберите «Добавить на домашний экран» — приложение будет запускаться с иконки, как обычное.

## Почему это работает

Повторения по FSRS возвращают слово ровно в момент, когда оно начинает забываться. По открытым бенчмаркам такой подход примерно на 25% эффективнее классических карточек: тот же уровень запоминания при заметно меньшем числе повторений.

## Возможности

- **Колоды и карточки** — вручную или через нейросеть; у каждого слова транскрипция, озвучка, коллокации с примерами и уровень CEFR
- **Умные повторения** — очередь на сегодня, порции, самооценка от «Снова» до «Легко», по которой алгоритм подстраивает интервалы
- **Свободные режимы** — «Все слова подряд», тест с вариантами ответа, сборка слова по буквам и «Знакомство» с новыми словами из пула сообщества
- **Сообщество** — общий пул из ~1800 частотных слов, доступный с первого запуска; публикуйте свои карточки, смотрите чужие, копируйте себе по одной или группами
- **Серия дней** — напоминания бота в выбранные часы, push «серия под угрозой», поздравления с рубежами
- **Статистика** — календарь активности за полгода и «хронотип памяти»: в какой час суток вы запоминаете лучше всего
- **Под себя** — озвучка с выбором голоса, тёмная и светлая темы, русский или английский интерфейс, упрощённый вид, показ примеров на карточках
- **Ваши данные** — экспорт и импорт словаря, обработка персональных данных по 152-ФЗ с отдельным согласием
